# Testing Playwright with Cucumber-JS on LambdaTest

> Automated End-to-End (E2E) testing of web apps with Playwright and Cucumber.js across real browsers and operating systems on TestMu AI.

## Setup
* Clone the repo. Run `cd playwright-cucumber-js`
* Install dependencies. Run `npm install`

## Running your tests
- To run a single test, run 
  ```npm run test```
